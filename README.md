# endirocoffee

Endiro Coffee concept site (Uganda). Static pages + Vercel functions. Free stack: Vercel Hobby, Neon free tier.

- Mobile money: MUDA Pay (MTN, Airtel).
- Crypto: NOWPayments, see `CRYPTO.md`.

## Setup
1. `bash ship-endiro.sh` (adds the site files from endiro-site.zip, one time).
2. `bash setup-crypto.sh` (keys to Vercel, Neon tables, production deploy).

After that, every push to `main` deploys on Vercel.
